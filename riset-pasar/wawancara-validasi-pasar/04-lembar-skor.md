## Skor inti

### S1 — Masalah workflow aktual

- **0:** tidak ada masalah; workflow cepat dan konsisten.
- **1:** gangguan sesekali, tanpa dampak berarti.
- **2:** masalah berulang pada persiapan, koreksi, pelacakan pola, atau laporan.
- **3:** masalah berulang dengan dampak jelas pada waktu, kualitas tindak lanjut, atau layanan.

**S1: 0 / 1 / 2 / 3**

Kejadian/bukti: ___

### S2 — Kebutuhan informasi untuk tindak lanjut

- **0:** informasi saat ini cukup; tidak membutuhkan pola/jenis kesalahan.
- **1:** ingin informasi tambahan, tetapi tidak mengubah tindakan.
- **2:** informasi yang hilang menghambat pemilihan latihan/tindak lanjut.
- **3:** sudah membuat workaround atau membayar alat/tenaga untuk kebutuhan itu.

**S2: 0 / 1 / 2 / 3**

Keputusan yang terhambat: ___

### S3 — Pemahaman pitch dan kontrol manusia

- **0:** salah paham; menganggap aplikasi menggantikan tutor/otomatis menentukan semuanya.
- **1:** memahami sebagian, tetapi tidak menangkap review manusia atau pilihan remedial.
- **2:** dapat menjelaskan latihan bervariasi, usulan diagnosis direview manusia, remedial dipilih tutor/orang tua, dan laporan pola.

**S3: 0 / 1 / 2**

### S4 — Komitmen operasional

- **0:** menolak/tidak ada langkah lanjut.
- **1:** minat verbal atau minta informasi saja.
- **2:** memilih murid dan/atau menyetujui jadwal onboarding.
- **3:** onboarding disepakati dan siap menjalankan uji dengan murid setelah consent.

**S4: 0 / 1 / 2 / 3**

### S5 — Bukti komersial (bukan skor WTP)

Pilih status tertinggi yang benar-benar terjadi:

- **0** belum ditawari
- **1** ditawari; menolak
- **2** ditawari; perlu tindak lanjut
- **3** menerima penawaran/menyetujui proses pembayaran
- **4** deposit diterima
- **5** pembayaran lunas diterima

**S5: 0 / 1 / 2 / 3 / 4 / 5**

Paket: ☐ Tutor Rp225.000 untuk 3 bulan, maksimal 10 anak ☐ Keluarga Rp30.000 untuk 3 bulan, 1 anak

Tanggal tawaran: ___ · tanggal/nominal uang diterima: ___

> Respons “murah”, “masuk akal”, atau angka harga hipotetis tidak menaikkan S5.

- **C** consent/privasi/data
