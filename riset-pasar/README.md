# Riset Pasar

Validasi kebutuhan & pemetaan kompetitor untuk produk diagnosis kesalahan
matematika SD (kode B/K/H/E/T/N). Dokumen di folder ini adalah bukti pasar dan
snapshot keputusan pada tanggal riset, bukan backlog teknis aplikasi. Untuk
arsitektur/pekerjaan aktif lihat `../CLAUDE.md`, `../produk/README.md`, dan
kode/test `../mesin/`.

Berisi:

- Analisis kebutuhan dan potensi pasar (data PISA/AKM, 18 item kompetitor,
  pemetaan harga & risiko).
- Protokol wawancara validasi pasar.
- Catatan wawancara lapangan.

Acuan untuk keputusan produk — bukan kode. Kalau mencari implementasi,
lihat [`../produk/`](../produk/) atau [`../mesin/`](../mesin/).
