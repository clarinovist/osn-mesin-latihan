Catatan keputusan & diskusi internal.

## `plan/`

Rencana bertanggal — ditulis sebelum implementasi, diarsipkan setelah
selesai. Daftar terkini di [`plan/`](plan/).

Isi `plan/` masuk `.gitignore` (lihat `docs/plan/` di `.gitignore`):
rencana memuat detail internal yang tidak perlu terbuka. Hapus dari
.gitignore kalau memang sengaja mau dipublikasikan.

Kalau mencari spesifikasi produk yang sudah jadi, lihat
[`../produk/`](../produk/). Kalau mencari README, lihat
[`../README.md`](../README.md).
