## `plan/`

Rencana bertanggal — ditulis sebelum implementasi, diarsipkan setelah selesai.
Spesifikasi permanen siklus aktif ada di
[`../produk/Siklus Belajar Terpandu.md`](../produk/Siklus%20Belajar%20Terpandu.md).
Rincian implementasinya disimpan lokal sebagai
`docs/plan/2026-09-06-siklus-belajar-terpandu.md`; karena `docs/plan/`
gitignored, berkas itu tidak dijamin tersedia pada clone lain. Ringkasan
kontraknya juga ada di `../CLAUDE.md`.

Isi `plan/` masuk `.gitignore` (lihat `docs/plan/` di `.gitignore`):
rencana memuat detail internal yang tidak perlu terbuka. Hapus dari
`.gitignore` kalau memang sengaja mau dipublikasikan.

Dokumen `../produk/` mencampur prinsip pedagogis aktif dan artefak keputusan
historis. Baca `../produk/README.md` lebih dahulu untuk hierarki dan status
masing-masing dokumen.
