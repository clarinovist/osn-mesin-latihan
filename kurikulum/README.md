# Kurikulum

Berkas acuan untuk latihan OSN SD:

- Kurikulum fondasi IPA OSN SD 2027
- Kurikulum fondasi Matematika OSN SD 2027
- Tes Kalibrasi — lembar soal anak
- Tes Kalibrasi — panduan orang tua
- Uji Ulang Lisan — tindak lanjut

Semua PDF, tidak ada kode. Dipakai untuk menyusun lembar latihan di
[`../latihan/`](../latihan/) dan parameter generator di
[`../mesin/generator.py`](../mesin/generator.py).
