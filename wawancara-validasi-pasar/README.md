# Paket Wawancara Validasi Pasar — Orang Tua Anak SD

Folder ini berisi seluruh instrumen wawancara, siap cetak/pakai.
Protokol lengkap & alasannya: `../Protokol Wawancara Validasi Pasar.md`.

## Isi folder & urutan pakai

| # | File | Dipakai kapan |
|---|---|---|
| 1 | `01-naskah-wawancara.md` | Saat wawancara — bacakan langsung (naskah verbatim) |
| 2 | `02-formulir-skrining.md` | Sebelum wawancara — cek kelayakan responden (via telepon/pesan) |
| 3 | `03-lembar-persetujuan.md` | Awal wawancara — bacakan + tanda tangan |
| 4 | `04-lembar-skor.md` | Per responden — diisi pewawancara 5 menit setelah wawancara |
| 5 | `05-lembar-rekap.md` | Setelah semua wawancara — rekap 20–30 responden untuk sintesis |
| 6 | `06-kartu-pitch.md` | Blok D — tunjukkan ke orang tua (cetak atau di HP) |

## Aturan emas (dari protokol)

1. **Jangan sebut produk sebelum Blok D.** Blok A–C harus murni pengalaman orang tua.
2. **Jangan mengarahkan jawaban.** Probe netral: "bisa ceritakan lebih lanjut?", "ada lagi?"
3. **Catat jawaban verbatim yang penting** (kutipan) — lebih berharga dari rangkuman.
4. **Waktu 30–40 menit.** Kalau molor, potong Blok C (paling tidak kritis).
5. **Skor diisi SETELAH wawancara**, bukan saat berlangsung (bias konfirmasi).

## Target

- 20–30 responden: kelas 4–5 (15), kelas 3 & 6 (5–10), separuh pernah les / separuh tidak, Jabodetabek + 1 kota Java urban.
- Selesai 3–4 minggu → laporan sintesis → keputusan go/no-go (ambang di `05-lembar-rekap.md`).
